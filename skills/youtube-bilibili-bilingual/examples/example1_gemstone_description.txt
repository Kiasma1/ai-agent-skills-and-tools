【视频简介】
珠宝设计师从硬度、韧性、解理与性价比，把 26 种常见宝石从「坑货」排到「神级」。
为什么祖母绿要切掉尖角、欧泊会「炸裂」、莫桑石和培育钻为何常年 S 级、红宝石/蓝宝石的刚玉为何被叫 God Tier——一次说清。

【本视频排名总结 / Ranking Summary】
（原作者视角：Jewelry Designer Mason Mignanelli）

■ God 级 · God Tier
· 刚玉（红宝石 / 蓝宝石） / Corundum (Ruby / Sapphire)

■ S 级 · S Tier
· 莫桑石 / Moissanite
· 培育钻石 / Lab Diamonds
· 尖晶石 / Spinel
· 帕拉斯石橄榄石（陨石来源） / Pallasite Peridot

■ A 级 · A Tier
· 石榴石（多数品种） / Garnet (most varieties)
· 金绿宝石 / Chrysoberyl（含亚历山大石 / Alexandrite 因价格落 A）

■ B 级 · B Tier
· 立方氧化锆 / Cubic Zirconia
· 翠榴石 / Demantoid Garnet（略软，从石榴石中单列）

■ C 级 · C Tier
· 海蓝宝石 / Aquamarine
· 石英类（紫晶、黄晶等） / Quartz family
· 天然钻石 / Natural Diamonds（性能强但溢价高）

■ D 级 · D Tier
· 摩根石 / Morganite
· 橄榄石 / Peridot（普通款）

■ E 级 · E Tier
· 祖母绿 / Emerald
· 合成金红石 / Synthetic Rutile

■ F 级 · F Tier
· 珍珠 / Pearls
· 欧泊 / Opals
· 长石类（月光石、日光石、天河石、拉长石等） / Feldspar (Moonstone, Sunstone, Amazonite, Labradorite)
